# ClothesMarket 🛍️

ClothesMarket is a multi-city clothing marketplace that connects local clothing sellers with customers through a modern web platform.

## 🚀 Features

* 🔐 User authentication & Google Login
* 🛍️ Product browsing, search & sorting
* ❤️ Wishlist
* ⭐ Product reviews & ratings
* 📍 Multi-city marketplace
* 🏪 Seller dashboard
* 👨‍💼 Admin dashboard
* 🖼️ Cloudinary image management
* 📧 Email & OTP verification
* 💳 Razorpay subscription payments
* 📱 PWA support

## 🛠️ Tech Stack

**Frontend**

* React
* Vite
* Tailwind CSS

**Backend**

* Node.js
* Express.js
* MongoDB
* JWT
* Passport.js

**Services**

* MongoDB Atlas
* Cloudinary
* Razorpay
* Resend

## ⚙️ Getting Started

Clone the repository

Install dependencies:

```bash
cd backend
npm install

cd ../frontend
npm install
```

Create the required `.env` files and add your API keys and configuration.

Run the development servers:

```bash
# Backend
npm run dev

# Frontend
npm run dev
```

## 🎯 Project Goal

To build a scalable marketplace that helps local clothing businesses reach customers online while providing a smooth shopping experience.
